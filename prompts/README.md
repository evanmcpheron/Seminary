`00-master-project-constitution.md` governs every task. Numbered prompts are executed separately and define the permitted write scope. The `02a` prompt is an intentionally separate scheduling gate added between import and course research.

| 11 | Audit sources |
| 12 | Audit theology |

Default execution is one prompt, one declared unit, one provenance record, validation, and stop.
